04 / ABOUT TERRAVISTA

A clearer way to read the signal.

TerraVista AI is an educational interface for exploring how a simple machine-learning model interprets place-based housing data.

Technology

Built to be legible.

Flask serves the application, Python and scikit-learn power the prediction, and this lightweight client-side view layer keeps navigation fast without adding a framework.

Methodology

One measured baseline.

A linear regression model uses 13 source features to estimate historical median home value. Model notes show performance on a reproducible held-out test split.

Limitations

Context matters.

The Boston Housing dataset is historical and contains ethically problematic features. These estimates are not appraisals and should not guide lending, pricing, or decisions about people.
